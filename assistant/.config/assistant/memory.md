## 2026-08-30 — Panel scroll/selection internals

BTT ListView: newest message at contentY == -height, oldest at -contentHeight; both collapse to -height when content fits. A Flickable with content smaller than viewport stops delivering wheel events to children — wheel faces must be siblings. Touchpad wheel = pixelDelta at event rate: apply 1:1, no animation, no notch quantising. Harness: /usr/lib/qt6/bin/qmltestrunner -platform offscreen -input <file>; console.* prints as QDEBUG. Selection: Selection.qml singleton + SelectableArea.

Reading anchor (AssistantPanel.qml, the "panel pulls me while reading" fix): while unstuck the view anchors on a DELEGATE (updateReadAnchor/reaimReadAnchor; readIndex adjusted by count delta — appends prepend, count shrink = session switch → invalidate). contentHeight is noise-dominated during lazy delegate build (measured -3785px extrapolation swing in 2s, zero content moved); delegate y = (originY+contentHeight) − Σ heights of itself and newer items, so the noise cancels exactly. Capture points: onContentYChanged (unstuck+laidOut) and end of wheelPixels (its contentY write fires while stuck is still true — order is load-bearing).
